# Air Quality Dashboard

A real-time web application that visualizes air quality, weather conditions, and pollutant levels for any city worldwide — built as part of the **Plasma Air Interaction Project**.

## Features

- **City Search** — Search any city worldwide using city name or `City, Country` format
- **Real-time Weather** — Live temperature, humidity, wind speed, and weather condition
- **Air Quality Index (AQI)** — US AQI with color-coded status levels
- **Pollutant Breakdown** — SO₂, PM2.5, PM10, NO₂, CO levels in μg/m³
- **Pollutant Bar Chart** — Interactive Chart.js visualization of pollutant data
- **Interactive Map** — Leaflet.js map with city marker and AQI popup
- **City Comparison** — Compare AQI, temperature, humidity, PM10, and PM2.5 between two cities
- **Health Recommendations** — Personalized advice based on current AQI level
- **FAQ Guide** — Accordion-style guide explaining AQI, pollutants, and their health impacts
- **About Page** — Project overview, tech stack, and data source credits

## APIs Used

### 1. [OpenWeatherMap](https://openweathermap.org/)
- **Geocoding API** — Converts city name to latitude/longitude
  ```
  https://api.openweathermap.org/geo/1.0/direct?q={city}&limit=10&appid={API_KEY}
  ```
- **Current Weather API** — Fetches temperature, humidity, wind, and conditions
  ```
  https://api.openweathermap.org/data/2.5/weather?lat={lat}&lon={lon}&appid={API_KEY}&units=metric
  ```

### 2. [Open-Meteo Air Quality API](https://open-meteo.com/)
- **Air Quality API** — Fetches US AQI, PM2.5, PM10, NO₂, SO₂, CO, and ozone
  ```
  https://air-quality-api.open-meteo.com/v1/air-quality?latitude={lat}&longitude={lon}&current=us_aqi,pm10,pm2_5,...
  ```

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or above)
- An [OpenWeatherMap API key](https://home.openweathermap.org/api_keys) (free tier works)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/adityaranjan05/air-quality-dashboard.git

# 2. Navigate into the project
cd air-quality-dashboard

# 3. Install dependencies
npm install

# 4. Create a .env file in the root
touch .env
```

### Environment Variables

Add this to your `.env` file:

```env
VITE_WEATHER_API_KEY=your_openweathermap_api_key_here
```

### Run the Dev Server

```bash
npm run dev
```

Then open `http://localhost:5173` in your browser.

### Build for Production

```bash
npm run build
```

| 0 – 50 | Good |

| 151 – 200 | Unhealthy |
| 201 – 300 | Very Unhealthy |
| 300+ | Hazardous |

## About the Project

This dashboard was developed as part of the **Plasma Air Interaction Project**, which studies the interaction between plasma generated by a Tesla coil and the surrounding air. The web interface monitors environmental parameters and visualizes air quality data in real time.
